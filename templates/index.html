How Checkout Works

1. Configure your OVH account and payment methods on the OVH Manager.

2. Set default checkout preferences in Settings → Billing (auto-pay, duration, etc.).

3. Browse the Catalog tab, select a plan, and click "Order Now".

4. The order is placed via the OVH API - no manual OVH Manager clicks needed.

5. For flash sales, use the Sniper to auto-order when stock appears.
